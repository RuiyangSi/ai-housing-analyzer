# 展示系统实现说明

## 📋 概述

本文档详细说明房价分析页面的展示系统是如何工作的，包括数据流、渲染机制和交互功能。

## 🔄 完整数据流程

```
用户访问页面 
  ↓
前端 JavaScript 加载 (analysis.js)
  ↓
发送 API 请求 → /api/city/{city_name_en}/deep-analysis
  ↓
后端处理 (app.py) → HousingAnalyzer 分析数据
  ↓
返回 JSON 数据
  ↓
前端接收数据 → 存储到 analysisData 变量
  ↓
调用 renderAnalysis() → 渲染所有组件
  ↓
用户看到完整的分析报告
```

## 📦 核心组件

### 1. 数据获取层

**文件**: `static/js/analysis.js` (第 9-69 行)

```javascript
// 页面加载时自动执行
document.addEventListener('DOMContentLoaded', async function() {
    // 1. 发送请求获取数据
    const response = await fetch(`/api/city/${cityNameEn}/deep-analysis`);
    
    // 2. 解析 JSON 响应
    const result = await response.json();
    
    // 3. 存储数据并开始渲染
    if (result.success && result.analysis) {
        analysisData = result.analysis;
        renderAnalysis();  // 开始渲染
    }
});
```

**关键点**:
- 使用 `fetch` API 进行异步请求
- 30秒超时保护
- 错误处理和用户提示

### 2. 数据渲染层

**文件**: `static/js/analysis.js` (第 71-114 行)

`renderAnalysis()` 函数是核心调度器，按顺序渲染各个部分：

```javascript
function renderAnalysis() {
    // 1. 显示/隐藏加载状态

    renderPriceTrendECharts(...);  // 价格趋势图
    renderPriceBoxPlot(...);       // 箱线图
    renderInvestmentRadar(...);    // 雷达图
    renderPriceRangeECharts(...);  // 价格区间分布
```

### 5. AI 分析展示

**文件**: `templates/analysis.html` (第 589-631 行)

使用 **Server-Sent Events (SSE)** 进行流式展示：

```javascript
async function loadCityAIOverview() {
    const contentDiv = document.getElementById('city-ai-overview-content');
    
    // 创建 SSE 连接
    const eventSource = new EventSource(
        `/api/city/${cityNameEn}/ai-overview-stream?role=${role}`
    );
    
    let fullText = '';
    
    // 接收流式数据
    eventSource.onmessage = function(event) {
        if (event.data === '[DONE]') {
            eventSource.close();
            return;
        }
        
        const data = JSON.parse(event.data);
        if (data.content) {
            fullText += data.content;
            // 实时渲染 Markdown
            contentDiv.innerHTML = renderMarkdown(fullText);
            // 自动滚动到底部
            contentDiv.scrollTop = contentDiv.scrollHeight;
        }
    };
}
```

**Markdown 渲染**:
```javascript

    // 4. 处理段落
```


## 🚀 性能优化

1. **懒加载**: 图表只在数据加载完成后才初始化
2. **响应式**: 使用 `window.addEventListener('resize')` 自动调整图表大小
3. **错误处理**: 每个渲染函数都有数据验证和错误处理
4. **超时保护**: API 请求有 30 秒超时限制

## 📝 总结

展示系统的核心流程：

1. **数据获取** → `fetch` API 从后端获取 JSON 数据
2. **数据存储** → 保存到 `analysisData` 全局变量
3. **数据渲染** → `renderAnalysis()` 调度各个渲染函数
4. **图表生成** → ECharts 库创建交互式图表
5. **内容注入** → 直接操作 DOM 插入 HTML 内容
6. **AI 展示** → SSE 流式传输，实时渲染 Markdown

整个系统采用**模块化设计**，每个功能都有独立的渲染函数，便于维护和扩展。
